# Security

Claustra is authentication infrastructure. Please do not publish exploitable vulnerabilities in a public issue.

Until a private reporting address is configured for the public repository, contact the repository owner privately. Include affected versions, reproduction steps, impact, and any suggested mitigation. Do not include real tokens, cookies, credential responses, email links, signing keys, client secrets, or personal data.

The initial implementation must complete independent review and OpenID conformance testing before it is treated as production-ready.
